# Üçüncü taraf bildirimleri

Bu repository yalnızca bu projenin kaynak kodu için MIT lisansı taşır. `models/weights/` altındaki iki bundle ağırlık MIT kapsamına girmez; dağıtım izni repository sahibi tarafından verilmiştir, ancak eğitim verisi ve model lisansları ayrıca doğrulanmalıdır.

| Bileşen | Lisans / not |
|---|---|
| PyTorch / torchvision | BSD-3-Clause |
| Ultralytics | AGPL-3.0 veya ticari Enterprise lisansı; kullanım biçiminize uygun lisansı ayrıca değerlendirin. |
| OpenCV | Apache-2.0 |
| Gradio | Apache-2.0 |
| NumPy | BSD-3-Clause |
| pandas | BSD-3-Clause |
| Plotly.py | MIT |
| Matplotlib | PSF-based license |
| Transformers | Apache-2.0 |
| Depth Anything V2 Small ağırlığı | Apache-2.0; Base/Large/Giant varyantları aynı lisans kapsamında değildir. |
| FFmpeg | Dağıtımınızın yapılandırmasına bağlıdır; kullanılan binary'nin lisans yükümlülüklerini kontrol edin. |

Kullanıcının sağladığı YOLO ağırlıklarının lisansı ve yeniden dağıtım hakkı kullanıcı sorumluluğundadır. Bu projede yalnızca açıkça yetkilendirilmiş iki bundle ağırlık istisnadır; başka ağırlıkları public repoya eklemeyin.
