# Güvenlik ve gizlilik

Bu proje yerel çalışacak şekilde tasarlanmıştır. Bulduğunuz güvenlik veya gizlilik sorununu public issue yerine repository sahibiyle özel olarak paylaşın.

- Kaynak videolarını ve `.env` dosyasını paylaşmayın. Yalnızca repository sahibinin açıkça yetkilendirdiği bundle ağırlıkları public repo kapsamındadır.
- Üretilen raporlar kaynak dosya adı ve mutlak yol içermez; yine de klinik veriyi paylaşmadan önce kurum politikasına göre inceleyin.
- Kimliksizleştirme model tabanlıdır; doğruluğu garanti edilmez. Klinik veri dışarı aktarılmadan önce insan denetimi gerekir.
